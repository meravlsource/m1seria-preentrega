# M1SERIA

m1seria es una tienda editorial ficticia de publcaciones y objetos.

El proyecto presenta una selección de dos libros, una remera y un poster. Inspirados en su universo visual.

# Tecnologías utilizadas
- HTML
- CSS
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree

# Estructura
El sitio cuenta con:
- Inicio
- Productos
- Reseñas
- Formulario de contacto 
- Footer

El objetivo del proyecto es aplicar los contenidos vistos hasta el momento durante el taller, meidiante una página web responsive y semánticamente estructurada.
